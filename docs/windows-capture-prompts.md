# Windows 官网演示与截图

请由你在自己的 Windows 电脑上，使用当前官网推荐下载所对应的 LightX2V Windows App，自行完成下面的生成与截图清单。先制作一张新的公开演示作品，再截取真实 App 窗口；不要使用测试截图或仅展示空白界面的截图。

## 官网截图的硬要求

- 在 App 中新建官网专用 **workspace**，使用如 `LightX2V Demo` 的中性名称。仅放本次新建且获准公开的演示，不带入原有创作历史、旧作品或私人参考图。
- 图内任何位置都不能出现**本机路径、用户名或 `ChatGPT` 字样**。模型路径、输出路径或演示目录路径也不例外；同时检查窗口标题、工作区名称、侧栏、历史区、提示词、状态区及结果区。
- 通过真实 App 控件收起模型准备、运行环境和路径信息区域，再采集正常创作视图。右侧可保留分辨率档（包括 1K）、比例和输出尺寸等正常创作设置，不要求隐藏整个右侧区域；但任何位置仍不得出现本机路径。若仍有上述内容，先调整实际界面，不要涂抹、模糊、遮盖、改写文字或伪造界面。
- 完整原图、细节裁切、网页压缩图和缩略图都要单独检查。完整原图必须先干净，不能只靠裁切把问题藏起来。

Mac 本轮受散热限制，原建筑试图使用 **512 分辨率档、3:2 比例、PE 关闭**，App 实际输出 **640 × 416，耗时 38.6 秒**，并非 512 × 512。用户已拒绝该试图，已废弃，不纳入官网。

Mac 的水豚演示已经完成，使用精确提示词 `A capybara wearing a wizard hat, oil painting`，实际输出为 1K / 1:1 / 1024×1024，PE 关闭；该作品保留在作品墙。蓝玫瑰现与水豚并列展示在作品墙，且其首页真实 App 演示已完成并逐图复核，提示词精确为 `A blue rose growing in the garden`，实际为 **1K / 1:1 / 1024×1024、8 步、PE 关闭**，生成 ID 为 `20261111-135300-8D88701B`。截图来自仅含一条蓝玫瑰记录的干净独立 workspace，模型准备折叠、右侧参数保留。Mac 现在停止继续生图，不重试、不批量、不试其他提示词或参数变体。下方 Windows 建筑示例仍由你自行采集。

当前 Mac 预览按用户指定，使用本机 `/Applications/LightX2V.app` **0.1.0 (1)** 已安装构建的英文界面重新展示已有蓝玫瑰，未重新生成，两项图库作品及原始输出均保持不变。该可执行文件 SHA-256 为 `c537f5af12c3c52eb7bbddd7bc39b42e8f487ac2aa0cd8e73370ff0c55b2f8ca`；尚未核实对应官方 Release 包，因此不再沿用旧 Stable 安装包来源摘要，最终发布门禁仍保留。英文主图、细节图与 JPEG 原图的文件及裁切记录见[总清单](capture-checklist.md#素材清单的发布复核字段)。这项 Mac 预览安排不改变下方 Windows 使用官方推荐下载版本的要求。

最终仍需六类真实作品齐备后才能发布，素材缺口不会以废弃试图、假图或重复图补齐。

## 采集步骤

1. 打开官方下载版本的 App，记录实际应用版本与下载的 Release 标签。保留安装包来源；不要以开发版或测试版冒充官网推荐下载版本。通过正常功能新建官网专用 workspace，确认里面没有原有创作历史。
2. 使用 App 正常提供的图像生成功能，输入上面的提示词。选用本机已正确安装、App 实际支持的模型；按设备能完成的设置生成，不必为了演示提高硬件负载。
3. 等待推理真实完成，确认结果已经显示，且界面中没有运行进度、下载进度或错误。不要开启测试/fixture 模式，也不要用导入的其他工具作品替代实际生成。
4. 检查画面是否适合公开展示。若结果不满意，可重新真实生成；不要手工合成结果或改写界面。
5. 让完整窗口包含生成结果及足够识别 App 的真实界面，只显示本次新的公开演示。通过正常控件收起模型准备、环境和路径区域；右侧分辨率档、比例与输出尺寸可以保留。确认任何位置都无原有创作历史、本机路径、用户名或 `ChatGPT` 字样，也无账号、通知及其他应用。使用正常窗口尺寸调整；不要求某个不存在的控件或专用展示模式，不以涂抹或伪造方式清理。
6. 用系统截图工具截取完整 App 窗口，保存为 PNG，原始宽度至少 1600 像素。不要发送经聊天软件二次压缩的预览图，不要放大低分辨率截图。若达不到尺寸，请提供原图并说明屏幕条件。
7. 保存同一张实际生成作品的原始输出图。另交一张结果区域的细节图，可以从已干净的完整窗口原图裁切，保留完整图并标注来源。逐张检查原图、细节图及后续压缩图和缩略图；任何一张都不能含原有历史、路径、用户名或 `ChatGPT` 字样。不要拼接、替换或伪造界面内容。
8. 一并提供实际版本、Windows 系统版本、深色/浅色主题与界面语言，并明确回复“截图及作品可在公开官网使用”，确认专用 workspace、收起路径区域和逐图检查均已完成。来源记录按 [总清单模板](capture-checklist.md#交付信息模板) 填写。

## 最小交付包

- `windows-main.png`：完整窗口，已完成真实生成，原始宽度至少 1600 像素。
- `windows-detail.png`：同一真实场景的细节图；允许从完整原图裁切。
- `windows-architecture-output.png`：截图中对应作品的原始生成输出。
- `capture-notes.txt`：真实版本、系统、主题、语言、下载来源、来源核验信息和可公开确认。

提示词和实际参数用于内部来源记录，不展示在官网访客作品弹窗中。若任何一项不确定，请写“未确认”，不要补猜测的模型、参数、性能或版本。
