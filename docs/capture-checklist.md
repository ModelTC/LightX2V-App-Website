新版官网使用真实的 LightX2V App 窗口与实际生成作品。Mac 素材由制作人员在用户允许的演示场景中协助采集；Windows 素材由用户在自己的 Windows 电脑上采集。

- 当前 Mac 截图按用户最新指定，改用本机 `/Applications/LightX2V.app` 已安装构建 **0.1.0 (1)** 的英文界面，应用包名为 `LightX2V.app`，可执行文件 SHA-256 为 `c537f5af12c3c52eb7bbddd7bc39b42e8f487ac2aa0cd8e73370ff0c55b2f8ca`。本轮只切换界面语言并重新展示、采集已有蓝玫瑰，不重新生成，也不改变两项作品及原始输出的来源记录。该已安装构建尚无核实对应的官方 Release 安装包，不再标记为旧 Stable 包截图。

## 采集前确认

- 常规采集、尤其 Windows，使用官网当前推荐的官方下载版本，记录实际平台、发布标签/渠道、版本及来源。Mac 的 `stable` 是滚动渠道，仅写“Stable”不足以区分两次安装包；能取得时同时记录该包的 SHA-256 或发布对应提交。当前 Mac 预览按用户指定使用上方已安装构建，必须保留其真实身份，不称为官网推荐的 Stable 包。
- 需要对应官网下载渠道的采集，从官方 App 仓库的 Releases 获取应用；不需要修改产品源码，也不需要启用测试、fixture、stub 或 mock 模式。当前 Mac 已安装构建的可执行文件摘要不能代替官方安装包摘要。
- 准备一条允许公开的官网演示提示词。Windows 用户先按 [Windows 采集说明](windows-capture-prompts.md) 自行生成建筑示例，再拍截图；Mac 的水豚与蓝玫瑰指定生成均已完成，不再继续生图；水豚与蓝玫瑰并列保留作品墙，蓝玫瑰同时用于首页真实界面，原 512 档建筑试图不使用。
- 在 App 中通过正常功能新建**官网专用工作区（workspace）**，仅放置本次可公开的新演示。工作区名称使用干净的中性名称，例如 `LightX2V Demo`；不要沿用带用户名、私人项目名或 `ChatGPT` 字样的原有目录名。
- 官网截图不得带入原有创作历史。不要以“看起来无害”或“已有本地文件”为由复用旧历史、私人提示词、参考图或作品。专用工作区中仅可出现本次获准公开的新演示。
- 截图前关闭通知、聊天、终端、日志与文件选择器。**图内任何位置都不得出现本机路径、用户名或 `ChatGPT` 字样**，也不得出现姓名、账号、邮箱、密钥及个人文件。路径即使只指向演示目录、模型或输出目录，也不能出现在官网素材中。
- 使用 App 的正常控件收起运行环境、模型准备及路径信息区域，切换到只展示公开演示的正常创作视图。右侧可以保留 **1K 分辨率档、比例和输出尺寸**等正常创作设置；不要求隐藏整个右侧区域。逐一检查窗口标题、工作区名称、侧栏、历史区、提示词、状态区和结果区；若还显示路径，先调整真实界面再采集。
- 不依靠涂抹、模糊、遮盖、替换文字或拼接窗口来清理截图，也不伪造一个不存在的“干净界面”。完整原图必须先满足要求，不能只靠后续裁切隐藏泄露内容。

## 每个平台必须交付

| 文件 | 要求 |
| --- | --- |
| `mac-main.png` / `windows-main.png` | 一张完整 App 窗口截图，保留真实窗口边界，原始 PNG 宽度至少 1600 像素；内容为已完成的真实生成结果；不能有加载、下载、报错或未完成进度。 |
| `mac-detail.png` / `windows-detail.png` | 一张体现创作结果与相关操作区域的细节图。可以从同一次完整截图合法裁切；必须保留原图，并在记录中标明裁切来源。不得把不同时间、平台或功能拼到一起。 |
| `mac-<category>-output.png` / `windows-architecture-output.png` | 在 App 中实际生成并保存的原始图像。截图中展示的作品应能与原始输出对应。不可用测试 fixture、UI 检查占位图、网页插画或其他生成工具的作品替代。 |
| `capture-notes.txt` | 记录下方交付信息，并明确确认截图和生成作品可在公开官网使用。 |

完整截图需要在足够大的屏幕或原生高 DPI / Retina 截图中获得；不要放大低分辨率截图来满足 1600 像素。若屏幕条件不满足，先告知实际分辨率，保留原始截图，不插值放大。不要为截图虚构硬件、耗时或速度。

## 六类作品

作品库覆盖以下六类，均须由真实 App 推理生成。类别只描述画面内容，不代表新增产品能力。

| 类别 | 公开演示方向 | 采集安排 |
| --- | --- | --- |
| 摄影 Photography | 无人物的自然或静物摄影；明确为 AI 生成作品 | Mac 候选方向；本轮暂停新增生成 |
| 建筑 Architecture | 无标识、无人物的原创建筑场景 | Windows 默认采集；提示词见单独说明 |
| 产品 Product | 无品牌的原创器物、材质与棚拍光影 | Mac 候选方向；本轮暂停新增生成 |
| 插画 Illustration | 原创题材与风格，不模仿具名在世艺术家 | Mac 候选方向；本轮暂停新增生成 |
| 海报 Poster | 原创活动或抽象主题，不使用真实品牌或未经授权素材 | Mac 候选方向；本轮暂停新增生成；文字逐字检查 |
| 概念 Concept | 原创环境、空间或视觉概念 | Mac 候选方向；本轮暂停新增生成 |

这六类是最终目标，不是本轮 Mac 的批量生成任务。水豚与蓝玫瑰均已完成并列入作品墙，蓝玫瑰同时用于已复核的首页演示；Mac 现在不再继续生图。原建筑试图已废弃。Windows 是否重试由用户依据设备条件自行决定。不能用后期绘制补出 App 未生成的画面。作品标题和说明可以整理为中英双语，但不得改变其来源、平台与实际生成能力。

## 发布前验收

- 两个平台各有一张完整窗口原图和一张细节图；平台、主题和版本记录完整。
- 窗口与作品是真实生成完成状态，来源能追溯至实际 App 和官方下载版本；截图来自官网专用 workspace，仅展示本次公开新演示。
- 逐张检查完整 PNG 原图、细节裁切、网页压缩图和缩略图：均无原有创作历史、本机路径、用户名、`ChatGPT` 字样或其他个人信息。不能以缩略图较小或已裁切为由跳过检查。
- 模型准备和路径区域通过真实控件收起；原图干净，无涂抹、遮盖、替换文字或拼接伪造。
- 六类作品齐全、无 fixture、无无关私人内容，全部得到明确的可公开确认；此门禁不因本轮 Mac 负载限制或指定替换安排而降低。未齐备时不最终发布。
- 完整截图不失真、不插值放大，细节裁切有原图；网页衍生压缩保留原始素材。
- 中英文标题和类别对应同一份素材；访客作品弹窗不暴露内部提示词或参数。
