03 / A LITTLE MORE TO KNOW

开始之前。

关于下载、安装和本地创作。

LightX2V 桌面应用可以做什么？+
Mac 和 Windows 应用均基于 LightX2V 与 Qwen-Image，支持本地文字生成图像和参考图像编辑，并可使用 llama.cpp 增强提示词。具体功能与支持模型以各平台仓库说明为准。
我的电脑可以运行吗？+
Mac 版需要 Apple Silicon 芯片和 macOS 14 或更新系统，项目已在 24GB 统一内存的 M4 Pro 上验证。Windows 版面向 Windows 11 x64，AMD ROCm / NVIDIA CUDA 支持处于预览阶段，无需 WSL。不同模型需要不同内存、显存与存储空间，请查阅 Windows 硬件验证记录 ↗。
Mac 首次打开提示无法验证开发者，怎么办？+
确认应用来自官方仓库的 Releases 后，先尝试打开一次，再到「系统设置 → 隐私与安全性」找到 LightX2V，点击「仍要打开」，并按系统提示确认。请参阅 Mac 安装说明 ↗。
Windows 下载后如何安装？+
完整解压 ZIP 文件，运行 LightX2V.Windows.exe，并按向导准备运行环境与下载模型。目前 Windows 版本为未签名的预览版。具体步骤请查看 Windows 安装指南 ↗。
Stable、Latest 和 Preview 有什么区别？+
Mac 的 Stable 是推荐下载渠道；Latest 提供较新的构建，适合尝鲜。Windows 当前提供 Preview 预览版，功能与硬件兼容性仍在迭代。遇到问题可前往对应应用仓库提交 Issue。
需要一直联网吗？+
首次安装运行环境和下载模型时需要联网。图像推理在本机运行；重新下载模型、更新应用或获取其他依赖时仍需要网络。
